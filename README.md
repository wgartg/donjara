# みんなのドンジャラ

部屋コードで集まって、2〜4人で遊べるオンライン対戦ドンジャラ。人数が足りなければCPUも入れられる。
ブラウザだけで動く。対戦のデータは Firebase(Firestore)に置く。

## 遊び方

1. 名前を入れて「部屋を作る」
2. 「招待リンクを送る」で友達にリンクを送る(開くだけで部屋コードが入る)
3. メンバーがそろったら、ホストが「対局開始」

ルールはゲーム画面の「あそびかた」に全部のってる。CPUはホストの画面で動くので、対局中はホストもページを開いたままにしておく(ホストがいなくなると、ほかの人の画面が代わりに動かす)。

### できること

- **写真アイコン**:ロビーの「＋写真」から自分の写真を選ぶと、小さな正方形に縮めてみんなの画面に出る
- **顔パイ**:参加している人の顔の牌が1人1枚ずつ山に入る。どの牌の代わりにもなる。自分の顔であがると「じぶん大好き」、人の顔なら「ともだちパワー」
- **決めゼリフ**:リーチとあがりのセリフを決めておくと、カットインに出て、ブラウザが声で読み上げる(吹き出しボタンで声のオン/オフ)
- **お題**:半分くらいの局で特別ルールが出る(ラッキー祭り・金のパイ・倍々ドンジャラ・リーチ祭り・チームの日)
- **CPU 9人**:性格ちがい(リーチ好き、しんちょう派など)。「えらんで入れる」で選べる
- **称号とアイコンの枠**:あがった回数で称号が上がり、役図鑑が集まるとアイコンの枠が銅→銀→金になる(この端末に保存)
- **卓の色**:ホストが みどり・あか・よる・さくら から選べる

### みんなで遊ぶしくみ

- **観戦と予想**:対局中の部屋はロビーの「対局中の部屋」から観戦できる(始まった部屋のコードを入れても観戦になる)。序盤のうちに「この局はだれがあがる？」を予想できて、いちばん当てた人が「予想王」
- **応援**:観戦している人のスタンプは、卓の吹き出しに出る
- **席の引き継ぎ**:観戦している人は、CPUの席をそのまま引き継いで途中から参加できる
- **拍手**:だれかがあがったら3.5秒の連打タイム。いちばん連打した人が「盛り上げ王」
- **ないしょ話**:スタンプを1人にだけ送れる。ほかの人には「送ったこと」だけが見える
- **お題の投票**:局のはじめに3つのお題か「なし」から投票(6秒)
- **持ち時間**:1手15秒/30秒/なし。切れるとツモ切り、2回続くと代打CPUに交代。途中で抜けた人の席も代打CPUが打つ(戻ったら「自分で打つ」)
- **しょんぼり**:ふりこんだ人は次の局、アイコンと顔パイに涙がつく
- **因縁ボード・みんなの殿堂**:同じメンバーの通算成績と、歴代の高い手が残る
- **声スタンプ**(このGitHub版だけ):自分の声を2秒録っておくと、リーチやあがりのときにみんなの画面で鳴る。マイクの許可が必要
- **Claude実況**(claude.ai版だけ):結果画面のボタンで、Claudeが実況・総評を書いてくれる(押した人のClaudeの利用分を使う)

## 公開のしかた(最初の1回だけ)

### 1. Firebase

1. [Firebase コンソール](https://console.firebase.google.com/)で新しいプロジェクトを作る
2. **Firestore Database** を作成する(ロケーションは `asia-northeast1` がおすすめ)
3. Firestore の「ルール」タブに [`firestore.rules`](firestore.rules) の中身を貼って「公開」(**観戦・声スタンプ・因縁ボード・殿堂の追加でルールがまた変わった。前のルールを貼った人も、新しい中身に貼りかえて「公開」し直す**)
4. **Authentication** → ログイン方法 → **匿名** を有効にする
5. プロジェクトの設定 → マイアプリ → ウェブアプリを追加して、出てきた `firebaseConfig` の値を [`firebase-config.js`](firebase-config.js) に貼る

### 2. GitHub Pages

1. このリポジトリの Settings → Pages
2. Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 少し待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べる

### 古い部屋を自動で消す(なくてもいい)

Firestore → TTL → ポリシーを作成 → コレクション グループ `rooms`、タイムスタンプのフィールド `expireAt`。
最後の手から2日たった部屋が自動で消える。同じように、コレクション グループ `fans`(観戦・予想の記録)にも `expireAt` で TTL をつけておくと片づく。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | ゲーム本体(画面・ルール・CPU) |
| `firebase-backend.js` | Firestore と匿名ログインへのつなぎ(部屋・観戦・写真・声・因縁ボード・殿堂) |
| `firebase-config.js` | Firebase の設定(自分の値を貼る) |
| `firestore.rules` | Firestore のセキュリティルール(`rooms`・`rooms/*/fans`・`faces`・`voices`・`rivals`・`hall`) |

## メモ

- `firebase-config.js` の値は、サイトに公開される前提のもの。データの守りは `firestore.rules` でかけている(部屋を作れるのは本人、書き換えられるのは参加者、消せるのはホストだけ。写真を置けるのは本人だけで、中身は小さな画像だけ)
- 写真は 112px 角の JPEG(数KB)に縮めてから `faces/<uid>` に置く。元の写真はどこにも送らない。「写真をやめる」で消える
- 声スタンプは 8kHz の短い WAV(十数KB)にして `voices/<uid>` に置く。「消す」で消える
- ないしょ話の中身も部屋のデータに入っているので、開発者ツールを使えば見える。手牌と同じく身内で遊ぶ前提
- 手牌も部屋のデータに入っているので、開発者ツールを使えばほかの人の手牌がのぞける。身内で遊ぶ前提
- Firebase の無料プラン(Spark)で十分遊べる
- `index.html` は claude.ai のアーティファクトとしてもそのまま動く(そのときは claude.ai の保存先を使う)
